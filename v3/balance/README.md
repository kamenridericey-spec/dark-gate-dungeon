两个独立目标是消除前期怪物速通和控制长期竞速。I 级怪物和 II 级怪物现在只给素材；I 级考验新增物资接替原碎片；II、III 各有三张直接碎片考验。III 级共鸣、巡礼给两片。只按卡自身的等级查 DC。升 II、III 时额外摸到当阶遭遇。

每组比例固定：动态组队 50、积极独行 30、谨慎支援 20。城主各半使用压力部署或压碎片部署，两者都考虑可达纹样、共享任务及可承担角色的专长。冒险者根据公开牌面安排检定，小队会实际使用洞察、重掷、治疗、疾跑和改势等工具。这只近似这批策略，不能当作真人胜率。

额外策略检查显示，若旧中间方案允许城主在 II 级囤到足够升 III 和 IV 再开门，样本里压碎片会显著变强。因此新版前两次升阶各允许延后一大轮，之后必须先升级再部署。III 级等待期让延后开门也会推迟城主自身的最早终局。城主魂最多持有八枚，生命魂和城主魂仍分开记。III 级等待用现有大轮编号记录。上线后尤其关注城主满魂后剩余的回合是否有足够决策和威胁。

最终实测冒险者最快第5轮胜出，没有第4轮以内的冒险者胜局。城主胜局中 33 局升 IV、3 局全员失魂。最终对照与验收通过命令 `node tests/balance.mjs 91021` 和 `node tests/balance.mjs 320021` 重现。早期批次原始输出在本地 balance 目录。
