# 暗门地牢 · 第二版 V0.8.2

独立多人行动规则原型，第一版保留在站点根目录，本版在 `/v2/`。本地多人轮流操作：可切城主／冒险者视角，不是网络联机。页面关闭后不自动保存当前对局，请导出记录。正式卡牌动画与美术仍待完善。

## 运行

在本目录执行 `python -m http.server 3300`，浏览器打开对应本地服务。本目录使用原生浏览器模块，无 npm 依赖。

## 规则与数据

- `src/engine.mjs`：行动、部署、检定、魂经济、结算、救援、奇遇、道具规则。
- `data/cards.json`：25张普通收获，保留15／5／5；整合八张新道具，不另开牌库。
- `data/encounters.json`：原有遭遇及十组怪物和专属素材。
- `src/app.mjs`、`style.css`：可操作界面，临时目标参数选择区不代表最终交互设计。

## 验证

Node.js 22+（本次24）运行 `npm test`；`npm run simulate` 对激进独行／谨慎组队／动态组队各20局，输出到reports。模拟是公开信息启发式，不是真人或最优策略。浏览器检查脚本为tests/browser.py，需已有Playwright与Chromium，并先启动本地服务。

实现口径：升级在城主准备时，常规三张在新轮进入准备时已抽取，升级再额外一张；魅力多展示一货暂以承担者原身份判定，不把专长共享擅自扩大为全能力共享；裂隙新建替换旧通道；无人明确选择携带者时暂自动选同房首位存活者，可在界面重指定。移形换位保留强制目标，下一次主动机会自动进入开门流程，可再调整同地小队与承担者。

旧装备／神器沿用旧版主动使用后消耗的处理，是否应改为持续／每房限次未收到新版明确变更，需单独核对。未擅改5／7／12与最新魂收入。地图为16块四格模块的公开连通原型，包含分叉与汇合，并非最终印刷模板。
