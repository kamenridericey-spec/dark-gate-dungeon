# 暗门地牢 V0.8.3

在线：站点/v2/，根路径第一版保留。启动先选择冒险者或城主，另一方自动行动。地图从入口接四房板块，点击当前token及合格队友多选，再点房间探索／赶路。所有遭遇、检定与道具操作在中央弹窗，支持收起观察。道具和装备统一容量：心智3，其余2。

本地：在此目录运行 `python -m http.server 3301`。无需npm依赖。Node.js 22+ 执行 `npm test`，`npm run simulate` 生成三策略各20局；浏览器检查 `python tests/browser.py`，多轮两视角检查 `python tests/playthrough-ui-v083.py`，需已有Playwright和Chromium。

模块：src/rules.mjs参数；engine.mjs规则与状态；map.mjs四格板块与单侧门互通；ai.mjs实际对手；app.mjs与style.css可视化；data目录卡牌。历史原始素材不应覆盖本目录新素材。

最新规则差异见同级资料包的V0.8.3/规则与界面增量.md。只看承担者专长，不借同行；战败不给城主额外魂；优势依据最终骰法；替身受伤前可用，不回滚损失。旧装备沿历史规则主动使用后消耗，只是不再有单独槽。

当前是同机轮流操作、自动对手原型，不是网络联机；无自动存档，离开前导出记录。斜视旋转为轻量呈现，不宣称已完成真正三维。
